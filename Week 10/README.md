# Week 10 – Real Estate Data Analysis using Python

## Project Overview
This project focuses on analyzing house prices using Python. It explores the relationship between property features, location, and house prices through data analysis and visualization.

## Dataset
- **Dataset Name:** KC House Data
- **File Name:** `kc_house_data.csv`
- **Description:** Contains information about house prices, living area, property grade, waterfront status, and geographical location.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Tasks Performed

1. **Data Loading:** Imported the dataset using Pandas.
2. **Data Exploration:** Displayed the first and last five rows of the dataset.
3. **Dataset Information:** Checked the number of rows and columns.
4. **Missing Value Checking:** Identified missing values in the dataset.
5. **Living Area vs House Price:** Used a regression plot to analyze the relationship between living area and house price.
6. **Property Grade Analysis:** Used a box plot to compare house prices based on property grades.
7. **Waterfront Analysis:** Compared house prices of properties with and without waterfront access.
8. **Geographical Price Analysis:** Created a scatter plot to visualize house prices based on latitude and longitude.
9. **Investment Summary:** Identified the top five zip codes based on median house prices.

## Visualizations
- Living Area vs House Price – Regression Plot
- House Price by Property Grade – Box Plot
- House Price by Waterfront Status – Box Plot
- Geographic House Price Heatmap – Scatter Plot

## Key Findings
- House prices can be analyzed based on living area.
- Property grade helps compare house price distributions.
- Waterfront properties can be compared with non-waterfront properties.
- Geographic location helps understand house price variations.
- The top five zip codes were identified using median house prices.

## Conclusion
This project demonstrates how Python libraries can be used for real estate data analysis. Data visualization helps understand house price patterns and supports better real estate investment decisions.
